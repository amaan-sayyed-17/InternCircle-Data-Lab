# Task 2 — Exploratory Data Analysis (EDA) on Titanic

**Analysis script:** [task2_titanic_eda.py](../task2_titanic_eda.py)

This script loads Seaborn's Titanic dataset and explores its dimensions, first rows, data types, missing values, duplicate rows, numeric summary, and survival rates by passenger class and sex. It creates a cleaned copy for demonstration.

Run with:
```bash
python task2_titanic_eda.py
```
