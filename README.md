## Run locally

Python 3.10+ is recommended.

```bash
pip install -r requirements.txt
python task1_data_lab_setup.py
python task2_titanic_eda.py
python task3_data_visualization.py
python task4_sales_trend_analysis.py
python task5_iris_classifier.py
streamlit run app.py
```

Before submission, run the matching project, save genuine output screenshots/report if requested, and use the matching direct file link unless InternCircle specifically requests the repository URL. Certificate issuance depends on mentor review and portal requirements.
