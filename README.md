# InternCircle Data Science Lab

A practical Data Science project repository covering Python environment setup, exploratory data analysis, visualisation, sales trend analysis, a baseline machine-learning classifier, and a small Streamlit demo.

## Tasks
1. **Data Lab Setup** — verify Python and core libraries.
2. **Titanic EDA** — inspect data, handle missing values/duplicates, and summarize patterns.
3. **Data Visualization** — create histograms, box plots, bar charts, and a correlation heatmap.
4. **Sales Trend Analysis** — analyze a reproducible sample sales dataset and produce business recommendations.
5. **Machine Learning Classifier** — train/evaluate a Decision Tree classifier on the Iris dataset.
6. **Streamlit Demo** — run a simple interactive Iris prediction app.

## Run locally
Python 3.10+ is recommended.

```bash
pip install -r requirements.txt
python task1_data_lab_setup.py
python task2_titanic_eda.py
python task3_data_visualization.py
python task4_sales_trend_analysis.py
python task5_iris_classifier.py
streamlit run app.py
```

Some scripts download or load public datasets through installed libraries. Internet access may be needed the first time.
