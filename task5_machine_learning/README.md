# Task 5 — First Machine Learning Classifier

**Classifier script:** [task5_iris_classifier.py](../task5_iris_classifier.py)

Trains a Decision Tree classifier on the Iris dataset with a train/test split and reports accuracy, a confusion matrix, and a classification report.

Run with:
```bash
python task5_iris_classifier.py
```

Record the actual metrics and explain what they mean. This is an educational baseline model, not a claim of production-ready performance.
